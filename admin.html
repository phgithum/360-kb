设备与授权

每台设备第一次打开检索台时生成一个设备码，之后永久不变（存在浏览器本地，不会重复生成）。
清浏览器缓存或用无痕模式会生成新码，正常使用永远同码。
保存并「发布到全平台」后，所有设备的检索台都用这个密码。默认 12345678。
切到白名单后，名单外的设备打开检索台会被拒绝并显示自己的设备码——同事把它发给你，粘进这里即可。改完点「发布到全平台」即对所有人生效。

上传限制

控制检索台「上传知识」允许什么、拦截什么。视频和音频始终拦截。
每行一个格式一个上限，可直接修改或点 × 删除（删除 = 该格式改用下面的默认上限）。
表格里没有单独设置的文档格式按这个上限拦截。智谱官方单文件上限 100MB。
智谱官方规定 jpeg/png/webp 单张不超过 5MB。
粘贴的网页链接若指向这些格式（如 .mp4、.gif）会被拦截。

搜索统计（全平台）

所有设备的检索词汇总到 GitHub 的 360-kb-stats 仓库，这里一键汇总排行。需要先填统计 token 并发布。
这个 token 会随配置发布到前台（前台要用它上报搜索词），所以必须用单独的 Fine-grained token、只授权统计仓库，绝不能复用主仓库的 token。生成：GitHub → Settings → Developer settings → Fine-grained tokens → Generate，Repository access 选 Only select repositories → 360-kb-stats，Permissions 里 Contents 选 Read and write。
统计所有已上报的搜索记录，按次数排序（前 100 名）
还没汇总过。先填好统计 token → 发布到全平台 → 各设备搜索后回来点「汇总搜索排行」。

接入设备

所有打开过检索台的设备（按设备码）自动登记在这里，含首次接入和最近活跃时间。
点「刷新设备列表」查看。

全平台发布

把当前配置写入 GitHub 仓库的 config.json，所有设备打开检索台约 1 分钟内自动生效。Token 只保存在你本机浏览器，不会进网页代码。
发布前记得先点底部「保存配置」（保存 = 本机立即生效；发布 = 全平台生效）。
两步工作流：「保存配置」= 只对本机检索台立即生效；「发布到全平台」= 写入 GitHub，所有设备打开检索台约 1 分钟内生效。 Token 只存本机浏览器。用完可随时去 GitHub → Settings → Developer settings 撤销。
