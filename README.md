# 知识库检索台

一个纯静态单页网页，直连你的智谱（BigModel）知识库。没有后端、没有数据库、没有构建步骤，
双击 `index.html` 就能用，放到 GitHub Pages 上全团队都能用。

## 能做什么

- **检索**：关键词 / 混合 / 语义三种模式任选，结果直接给出原文链接，点开就能看原始文档
- **范围切换**：全部知识库、按类目、按单个库，随时切
- **AI 自动归类**：点一下「AI 归类」，自动把知识库按业务品类分组，生成左侧导航树
- **上传知识**：在网页里直接传文件（md/txt/pdf/doc/docx/pptx/xlsx/csv）或粘贴网页链接入库

## 首页用法

1. 打开页面，第一次会自动弹出设置框
2. 粘贴智谱 API Key（在 https://bigmodel.cn/usercenter/proj-mgmt/apikeys 获取）
3. 保存后左侧自动列出你的知识库
4. 点「AI 归类」生成分类导航
5. 顶部输入关键词，回车检索

Key 只存在你自己浏览器的 localStorage 里，不会写进网页代码，也不会上传到任何第三方。

## 部署到 GitHub Pages

仓库 `phgithum/huashu-prompts` 已经开启 Pages（分支 `main`，根目录）。

**方式一：一键脚本**

在本文件夹打开终端运行：

```
python deploy.py
```

按提示粘贴 GitHub Token 回车，脚本会上传 `index.html` 和 `README.md`。
Token 需要对该仓库有 Contents 写权限。

**方式二：网页手动上传**

1. 打开 https://github.com/phgithum/huashu-prompts
2. 点 `Add file` → `Upload files`
3. 把 `index.html` 拖进去，提交
4. 等待约 1 分钟，访问 https://phgithum.github.io/huashu-prompts/

## 只接入特定知识库

页面默认只显示 `index.html` 里白名单 `KB_WHITELIST` 中列出的知识库（当前只有「360客服知识库」）。
想接入其他库，把对应 id 加进白名单数组即可；留空 `[]` 则显示账号下全部知识库。
只有一个知识库时，「AI 归类」按钮会自动隐藏。

## 常见问题

**提示「模型不存在」**
AI 归类调用的模型默认是 `glm-4.6`。如果报错，去设置里把模型名改成 `glm-4-flash` 再试。

**搜不到刚上传的内容**
智谱需要一两分钟做切片和向量化。等一会儿再搜，或点左侧「刷新知识库」看文档数是否变化。

**结果没有「打开原文」按钮**
只有用链接方式收录的文档、或部分文件文档才有 `doc_url`。文件上传的文档在智谱里也能查看，
但接口不一定返回直链。

**关键词检索效果不好**
切到「混合检索」。它会同时走关键词和语义两条路再排序，召回率明显更高，代价是略慢一点。

**想换知识库归属的类目**
直接改智谱后台里的知识库名称，然后回网页点「清除分类」再点「AI 归类」重新生成。

## 安全提醒

- 网页是公开的，但**没有你的 Key 就无法读取任何数据**，所以不用担心内容泄露
- 智谱 API Key 和 GitHub Token 都不要写进 `index.html`，也不要提交到仓库
- 如果 Key 曾经发在聊天记录或其他不安全的地方，去控制台重新生成一次
